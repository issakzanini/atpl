About these sheets

What they are for

Revision, not first learning. Each page assumes the theory is already known and is arranged for the recall speed an airline screening test demands.

How they are built

Every sheet is one self-contained HTML file — no build step, no framework, no dependency beyond a web font. Open it from disk or from the web and it works the same.

Structure

Sections follow the real EASA syllabus numbering, so a topic here maps directly to the corresponding chapter in the CAE Oxford volumes.

Diagrams

Drawn as inline SVG to show a mechanism, not to decorate: the drag curve is plotted to scale, the frontal cross-sections carry their real slopes.
